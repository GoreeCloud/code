# Features

**Implemented at source level:** a development-only API, server-held provider credentials, a repository-specific allowlist and four sanitized read-only repository/collaboration endpoints. Automated unit tests and accessible static UI preview also exist.

**Not available:** hosted Git access, repository writes, hosted issue tracking, full pull-request workflows, review, packages, CI runners, permissions, user authentication, GoreeCloud AI interactions and official Glaze acceptance.

See [IMPLEMENTED-FEATURES.md](IMPLEMENTED-FEATURES.md) for source-level evidence and [PLANNED-FEATURES.md](PLANNED-FEATURES.md) for backlog priorities.
