# Features and capability inventory

The imported Forgejo v16.0.5 **source** contains implementations for Git repository hosting, users and organizations, access control, issues, pull requests and code review, project boards, wikis, releases, package registries, API integrations, and Actions/runner integration.

**Important distinction:** this inventory identifies inherited upstream source capability only. GoreeCloud runtime behavior, supported configuration, interoperability, scaling, accessibility and security require separate verification.

Future GoreeCloud features and migration status are tracked in [PLANNED-FEATURES.md](PLANNED-FEATURES.md).
