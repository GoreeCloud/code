# Features

**Implemented at source level:** a development-only API, protected server-side provider configuration and sanitized read-only repository mapping. Automated unit tests and accessible static UI preview also exist.

**Not available:** hosted Git access, repository writes, active issue tracking, pull requests, review, packages, CI runners, permissions, user authentication, GoreeCloud AI interactions and official Glaze acceptance.

See [IMPLEMENTED-FEATURES.md](IMPLEMENTED-FEATURES.md) for source-level evidence and [PLANNED-FEATURES.md](PLANNED-FEATURES.md) for backlog priorities.
