# Competitive objectives

Preserve the useful features and interoperability of Forgejo while building a distinctive GoreeCloud Code experience: accessible Glaze design, clear administration and onboarding, secure-by-default identity and policy enforcement, reliable recovery, data portability, privacy-minimized diagnostics, and integrated GoreeCloud services.

Benchmark against the inherited functional baseline; require evidence of parity or improvement before retiring existing components. No objective is yet asserted as achieved.
