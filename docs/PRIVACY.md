# Privacy scope and requirements

The bootstrap Code API does not implement analytics or intentional request logging, withholds service tokens from clients, returns `no-store` responses and projects only a small subset of upstream fields. This is a source-level implementation property, **not** privacy-policy acceptance or proof of real-world deployment.

Before any real user deployment, obtain Privacy Shield-governed purpose, consent (when applicable), personal-data handling, retention, access/export/deletion, audit treatment, incident response and processing-location evidence. Access checks must be enforced before reading private repositories.
